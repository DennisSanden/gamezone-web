# Patreon på GameZone

GameZone är gratis att spela. Ett aktivt Patreon-medlemskap ger följande förmåner som servern stödjer.

| Förmån | Vad ingår? |
| --- | --- |
| Köprioritet | Supporter får förtur när servern är full. Guldsupporter har en ännu högre nivå. |
| Extra Daily | En extra bonus utöver vanlig `/daily`, med egen belöningspool. |
| Särskilda Daily-drops | 20 % chans på ett förtrollat verktyg, samt chans på namngivet spelarhuvud från någon som spelat senaste veckan. |
| Namnfärg | Välj bland **14 färger** i chatt, TAB och ovanför huvudet. Röd och mörkröd är reserverade för admin/mod. |
| Supporterklubbhus | Tillgång till det skyddade klubbhuset. |
| Survival-klassförtur | Förtur vid tilldelning av begränsade klasser. |
| Survival Level 6 | Alla tio klassernas kraftiga level 6-bonusar. Kräver 15 000 XP från level 5 och **aktiv Patreon**. |
| Patreon-event | Tillgång om arrangörerna öppnar ett event endast för Patreons. |
| Supporterstatus | Rank i TAB, ett särskilt inloggningsmeddelande och synlighet på supporterlistan på webben. |

## Kommandon

`/patreon` öppnar en klickbar förmånsmeny som alla kan se.

`/patreon färger` öppnar färgpaletten för aktiva Patreons. Du kan också skriva exempelvis `/patreon rosa` eller `/patreon guld`. Återställ med `/patreon återställ`.

## Survival Level 6

Samla **29 400 XP totalt per klass**, inklusive 15 000 XP mellan level 5 och 6. Du kan samla XP även utan Patreon, men **level 6-bonusen är bara aktiv med Patreon**. När medlemskapet slutar förlorar du inte din XP, utan bonusen blir vilande tills du åter blir Patreon.

| Klass | Bonus ENDAST FÖR PATREONS |
| --- | --- |
| Soldier | +20 % skada mot mobs |
| Tank | 15 % mindre skada |
| Bowman | +30 % bågskada |
| Healer | Global Health läker 4 hjärtan |
| Summoner | +30 % summon-skada |
| Commander | 20 % extra skademinskning under stridshornet |
| Berserker | +30 % skada under 50 % HP |
| Necromancer | +30 % summon-skada |
| Resurrector | Återuppliva på 1,25 sekunder |
| Juggernaut | 15 % mindre skada |

Läs mer om klassernas grundbonusar i [Survival-guiden](/wiki/events/survival).

## Aktivering

Koppla Minecraft till Discord med `/discord`, öppna kanalen för Patreon-koppling i Discord och följ länken till Patreon. Har du redan ett medlemskap behöver du fortfarande koppla kontona.

Se hela presentationssidan och aktuella Supporter- och Guldsupporter-profiler på [gamezonemc.se/patreon](/patreon).
